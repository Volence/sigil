## KEY STRUCTURAL FACT (grounds every byte claim below)

`build.sh` runs pure `asl` — the canonical ROMs are assembled ENTIRELY from `.asm`
twins; no `SIGIL_EMP_*` gate is ever `-D`'d in a real build (build.sh:38-60 sets only
`__DEBUG__` / `SOUND_DRIVER_ENABLED` / `SOUND_DEBUG_HOTKEYS` / `SOUND_DBG_MIRROR`). The
`SIGIL_EMP_*` gates and the placed-`.emp` ROM are SIGIL-HARNESS TEST constructs
(`error_handler_port.rs`, `mixed_dac_rom.rs`). So:
- Adding a `.emp` file + its `ifndef SIGIL_EMP_*` gate arm is byte-neutral to build.sh
  by construction (the `ifndef` takes the `.asm` include; the gate is never set).
- "Gate-off dual rebuild exact" = build.sh produces the canonical CRCs, which holds
  trivially because the gate arm's `ifndef` branch is the unchanged `.asm` include.

### Shape

target is an engine symbol; SYSTEM_STACK is a `constants.asm` equ (`$FFFFFF00`), the
rest are labels. Ownership of the 64 entries:

- `EntryPoint` — boot.emp (.emp-owned, t23).

  PrivilegeViol, Trace, Line1010Emu, Line1111Emu, ErrorExcept, ErrorTrap` — error_handler

- `NullInterrupt` — engine.inc-INLINE `rte` stub (AS-side, out of scope; the brief).
- `HBlank_Vector_Slot` — RAM equ (AS-side, the trampoline slot).
Lines 40-47 are the FOUR comma-list `dc.l` lines (4 labels each: ErrorTrap×16, i.e.
TRAP 0-15 + reserved).

### P-A1 (step-0 BLOCKING probe): does `.emp dc.l` accept comma-lists of LABELS?

**VERDICT: YES — already supported. NO demanded feature.** `lower_dc`
(`sigil-frontend-emp/src/eval/asm.rs:771`) loops `for op in &instr.operands` over ALL
comma-separated operands; each `Value::Label(name)` pushes a `Cell::SymRef { width: 4 }`
(asm.rs:854-856) — one link fixup PER label element. The numeric comma-list is already
byte-proven (error_handler.emp:95-124 blob, 8 numerics/line). The t25 `dc.l <label>`
capability was single-label; the LIST case falls out of the same loop with no new code.

**Binding class of the probe (port-loop probe binding-class rule):** the real site is
LINK-TIME (the 64 targets resolve at link against .emp-owned + AS-side symbols), so the
probe must be link-time, NOT comptime-folded. P-A1 probe (`vectors_port.rs`): a synthetic
`dc.l L0, L1, L2, L3` compiled through lower→place→resolve→link with the four L labels
supplied as pinned AS-side sections at distinct VMAs; assert the four emitted 4-byte
slots resolve to those four VMAs (not a folded constant). POSITIVE CONTROL: the same
compile UNDOCTORED matches; a DOCTORED L2 VMA must diverge (verify the fixture fails when
doctored, passes when not — the t24 negative-probe rule). The full `vectors.emp` region
gate is itself the load-bearing proof; the probe isolates the list-of-labels capability.
