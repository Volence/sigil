# A/B evidence — art-streaming P2a Task 2: resumable ZX0 decoder (ZX0R) + boot equivalence self-test

**Parcel:** `art-streaming-p2-task2`. Adds ONE new engine byte-emitting section
(`engine/compression/zx0_resume.emp` → `ZX0R_Decompress`) plus a DEBUG-shape
equivalence self-test and three DEBUG RAM counters. This is an ADDITIVE parcel (a
new section + debug instrumentation), not a byte-neutral optimization, so the "A/B"
here documents the intended byte movement and the equivalence proof the self-test
performs, rather than a before/after semantic-equivalence of relocated code.

## What changed

  (a0,a1,a3) clobbers(d0-d2/a2) out(a0,a1)`, the stack-flat resumable twin of
  `ZX0_Decompress`. Control flow is a faithful restructure of `engine/compression/zx0.emp`
  (the `.get_elias`/`.elias_loop`/`.elias_bt` subroutine inlined at every site; `.len_elias`
  = the `.elias_bt` tail), exiting `jmp (a3)` instead of `rts`. Section span 0x80 (0x78
  code + 8-byte align pad to `GetSineCosine`). Present in ALL shapes (engine-agnostic).
- `engine/ram.emp` — three DEBUG-only words in the `@shape_divergent` block
  (`Dbg_PageIn_Preempts`/`Flushes`/`Resumes`), defined for Tasks 3-4; +6 bytes of

- `engine/debug/compression_selftest.emp` — appends a ZX0-vs-ZX0R byte+length
  equivalence walk over every act-pool page (buffer A `Art_Staging_Buffer`, buffer B

- `games/sonic4/map.toml`, `games/demo/map.toml` — `ZX0R_Decompress` inserted in the
  `order` list after `ZX0_Decompress` (the engine module places in both games).

## Equivalence proof (the self-test)

`CompressionSelfTest` (sonic4 DEBUG boot, interrupts off) decodes every act-pool page
twice — `ZX0_Decompress` → buffer A, `ZX0R_Decompress` → buffer B — and `raise_error`s on
any length or byte divergence. Blocking `ZX0_Decompress` is the oracle; ZX0R is proven
byte-identical to it over the real shipped pool. Oracle boot pass/fail is the
controller's step (subagents do no emulator work); the build-side proof is: all six
shapes green, `ZX0R_Decompress.__end` resolves (0x2928 debug), closure gate clean.
