## THE ONE JUDGMENT CALL FOR OVERSEER RATIFICATION — the drift guards

The all-gates flip surfaces a Stage-2 condition EARLY: **4 `.emp` drift guards
`ensure(extern("X") == X_mirror)` reference constants (VRAM_PLANE_B_BYTES) homed
ONLY in a `.asm` twin that is now GATED OFF** (bg.asm), so they fold to Poison
("symbol not defined in this link"), NOT a `Value(0)` drift failure. The driver
partitions: a real `Value(0)` drift stays a HARD failure; a Poison "not defined in
this link" guard is treated INAPPLICABLE (the twin it compares against is gone —
exactly the Stage-2 "guard retires with its twin" state). The whole-ROM byte gate
(native == asl) is the authoritative drift oracle for every USED constant — a
drifted value would change emitted bytes and fail the byte gate. This is NOT a
relaxation of drift DETECTION, but it IS a handling decision on unresolvable-extern
guards — flagged here for the overseer's countersign per the valve.

## Not silently dropped — the guards that keep firing

Every guard whose extern DOES resolve still runs and a `Value(0)` folds to a HARD
fail. Only the 4 whose twin `.asm` is gated off go inapplicable.

## CHECKPOINT-1 COUNTERSIGN — the allowlist-hardening condition (LANDED)

Countersigned with one hardening condition: pin the inapplicable set to a NAMED
allowlist (t24 both-directions), so a future typo'd/renamed extern or a new
twin-parity guard can never silently vacate a guard. Landed in
`native.rs::STAGE1_INAPPLICABLE_GUARDS` + `enforce_inapplicable_allowlist`:

- The observed Poison (unresolvable-extern) guard set MUST equal the allowlist
  EXACTLY, keyed by `(extern name, `.emp` site substring)`.
- A Poison guard NOT on the list → HARD FAIL ("unresolvable-extern drift guard not
  in the Stage-1 allowlist — either the extern name is wrong or a new twin-parity
  guard needs a ruling").
- An allowlisted guard that no longer folds to Poison (it now resolves, or drifted
  to `Value(0)`) → HARD FAIL ("allowlist is STALE").
- t24 negative controls in-suite: `native::allowlist_tests::{exact_allowlist_passes,
  unknown_poison_guard_is_rejected, stale_allowlist_is_rejected}`.
