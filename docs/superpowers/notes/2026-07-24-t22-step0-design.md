## Design decisions

### D1 — the entry-to-entry fall-through spelling (brief headline)

The twin: `S4LZ_DecompressDict:` (rebase preamble, 3 ifdebug lines +
adda/suba) falls through into `S4LZ_Decompress:` — TWO PUB entry points
sharing one body. NOT t21's P6 (bsr to local tail) and NOT t20's
`export .transfer:` (that emits an `Owner.label` DOTTED symbol — the flip
callers and the AS twin need the bare top-level name `S4LZ_Decompress`).

**The language already carries the exact construct: `falls_into`**
(`proc A (...) ... falls_into B { ... }` — lower/proc.rs: `B` must be the
item immediately after, `[proc.fallthrough-separated]` otherwise; shipped
consumer: collision.emp's Touch_* chain, EMPTY bodies, non-pub). Spelling:

    pub proc S4LZ_DecompressDict (a0, a1, a4: *DictBase, d4)
            clobbers(d0-d3/a0/a2-a4) out(a1) falls_into S4LZ_Decompress {
        // preamble
    }
    pub proc S4LZ_Decompress (a0, a1) clobbers(d0-d3/a2-a3) out(a0, a1) {
        // shared body
    }

UNPROVEN for our class (pub × pub, NON-empty first body, cross-module
callers of BOTH names, byte adjacency) → **PROBE P1** (below). Demanded-
feature path if it fails.

### D3 — `ifdebug` per-line gating (brief headline)

`ifdebug <instr>` (debugger.asm:144 — emit-if-`__DEBUG__`) ports to
statement-level `if DEBUG == 1 { ... }` grouping each CONSECUTIVE ifdebug
run (the ratified `ifdebug <x>` rule, campaign-port-loop assert bullet):

    if DEBUG == 1 {
        move.w  d4, d0
        andi.w  #1, d0
        assert.w d0, eq                 // dict length must be word-even
    }

Three sites: dict-even assert (2 loads + tst-form assert), version-byte
assert (1 load + cmp-form `assert.b d0, eq, #1`), dict-range assert
(2 loads + `assert.w d4, hs, d1` — REGISTER dest, cmp-form). The .emp
`assert` matches the twin macro byte-for-byte (t19 shipped; message embeds
the verbatim operand spellings). Register-dest assert has no corpus
consumer yet → folded into **PROBE P3**. Mid-proc shape-dependent bytes are
the byte gates' business (both shapes bound).

### D6 — the debug-only region machinery (brief headline)

The twin is whole-file `ifdef __DEBUG__` → the region EXISTS ONLY in the
debug shape (plain: zero bytes, no symbol). Resolution per surface:

- **.emp side**: NO language change. There is no item-level comptime `if`
  (t21 P5 finding, confirmed against ast::Item), and none is needed — the
  SHAPE lives at the build/harness level, exactly where engine.inc keeps
  it AS-side. compression_selftest.emp is unconditionally the debug code;
  debug-shape builds include the module, plain-shape builds DON'T.
- **engine.inc gate** (shape-split else arm; the data include stays
  AS-side):

      ifndef SIGIL_EMP_COMPRESSION_SELFTEST
          include "engine/debug/compression_selftest.asm"
      else
          ; sigil mixed build: CompressionSelfTest comes from
          ; engine/debug/compression_selftest.emp — a DEBUG-ONLY region
          ; (the twin is whole-file `ifdef __DEBUG__`): the plain shape
          ; emits nothing and placement stays put. The generated golden-
          ; vector data (CSelf_*/CSELF_*) stays AS-side here — the .emp
          ; consumes those symbols cross-seam at link.
        ifdef __DEBUG__
          org     $7204
          include "engine/debug/generated/vectors.asm"
        endif
      endif

- **pins.rs / repin.toml**: `COMPRESSION_SELFTEST: Region { plain_base:
  $624E, debug_base: $6FDC, plain_len: 0, debug_len: $228 }`. The repin
  tool cannot resolve a start symbol absent from the plain listing →
  **harness feature, TDD (P5)**: `[[region]]` gains `debug_only = true` +
  `plain_anchor = "<symbol>"` — start/end resolve against the DEBUG listing
  only; plain_len = 0; plain_base = the plain listing's address of
  `plain_anchor` (here `Sound_Init`, the next placement — keeping the
  emitted Region shape unchanged so every existing consumer compiles).
  Failing repin unit test first, then the feature, then the manifest row.
- **byte gate**: debug arm only (compile at DEBUG=1, byte-compare
  $6FDC..$7204 against s4.debug.bin). The PLAIN-side gate artifact is the
  gate-off/mixed pair: the t22 mixed arm's plain build sets the gate,
  includes NO module, and must still byte-match the full plain reference —
  that IS the "plain region is empty" proof (named in the gate list).
- **mixed arm**: `mixed_tranche22_{rom,debug_rom}` — gates
  `SIGIL_EMP_S4LZ` + `SIGIL_EMP_ZX0` + `SIGIL_EMP_COMPRESSION_SELFTEST`;
  .emp side places s4lz + zx0 (both shapes) + compression_selftest (debug
  arm ONLY). Cross-seam classes exercised at full scale: tile_cache.asm's
  `bsr.w S4LZ_DecompressDict`, load_art.asm's `bra.w S4LZ_Decompress` /
  `bra.w ZX0_Decompress`, boot.asm's debug `bsr.w CompressionSelfTest`
  (.asm→.emp), and the .emp→.asm data seam (CSelf_*/CSELF_* consumed at
  link from the else-arm's vectors.asm include).

### D7 — the CSelf_*/CSELF_* seam spelling (brief headline)

Emission site located: `tools/gen_compression_vectors.py` (run by build.sh
:89) writes `engine/debug/generated/vectors.asm` — 3 equ-class constants
(CSELF_PAYLOAD_SIZE / CSELF_PAYLOAD_SUM / CSELF_DICT_LEN) + 5 BINCLUDE'd
data labels (CSelf_S4LZ_Plain/_S4LZ_Dict/_Dict_Blob/_ZX0/_Expected). The
generator emits .asm ONLY → the .emp side consumes the symbols CROSS-SEAM
(the brief's equ/extern class). The port is code-only; the generator and
vectors.asm are untouched.

- **Address labels** (`lea (CSelf_S4LZ_Plain).l, a0` etc.,
  `Art_Staging_Buffer`): bare cross-seam names, resolve at link (the
  load_art Art_Staging_Buffer precedent). Step-1 keeps the twin's explicit
  `(sym).l` spelling; step 2 applies the bare width rule (these resolve
  abs.l — ROM addresses above the abs.w window).
- **Value symbols in immediates**:
  `move.w #CSELF_PAYLOAD_SIZE/2-1, d1` (×3), `move.w #CSELF_DICT_LEN, d4`,
  `assert.w d0, eq, #CSELF_PAYLOAD_SUM` (×3). These are LINK-TIME value
  expressions. Proven near-precedent: core.emp:53
  `move.w #(extern("Object_RAM_End")-extern("Object_RAM"))/4-1, d0` (`-`,
  `/` over extern() in an immediate) and core's bare `#Object_RAM` assert
  dests (label-in-immediate). UNPROVEN: the BARE-name spelling WITH
  arithmetic (`#CSELF_PAYLOAD_SIZE/2-1`) → **PROBE P4** decides the
  spelling: bare if it defers to link; else the extern() form
  (`#extern("CSELF_PAYLOAD_SIZE")/2-1`), site-commented as the link-time
  arm. The assert dest `#CSELF_PAYLOAD_SUM` is the proven bare
  label-in-immediate class (message spelling must stay verbatim for twin
  parity — P4's outcome does NOT change the assert spelling).
  OUTCOME: bare WON (see the probe table) — the .emp spells every CSELF_*
  site exactly as the twin does.
