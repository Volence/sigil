## 2. The design questions

1. **The census** — every generated file + every editor source + every generator,
   with tracked/ignored status, invocation point, and consumer; classify each output
   by the ratified convert-vs-embed test (semantic → typed `.emp` data;
   generated-deterministic → emission the build reproduces; opaque bulk → `.bin`
   embed). The sound precedents to reuse: generator-emits-`.emp`
   (`gen_sound_tables.py`, `zyrinx_player.py` pitchtable) and the emit-tool pattern.
2. **The reproducibility settlement (row 178)** — state precisely WHY a fresh
   worktree diverges (which inputs are gitignored/absent, what the generators do
   without them), and design the end state: **a fresh checkout of tracked sources
   builds byte-identical or fails loudly** — no silent wrong ROM. Rule whether the
   editor export tree fully determines the generated tree today; if not, what must
   become tracked. `seed-worktree.sh` should become unnecessary or an error-checked
   relic.
3. **The emission form** — for each `.asm` in the generated tree: does its generator
   emit `.emp` (semantic tables: entity placements, act descriptors, manifests,
   block dicts?) or a `.bin` the `.emp` side embeds (strips, tiles, compressed
   pages)? Where do emitted files live (regenerated-per-build like today, vs
   tracked like the sound outputs)? Argue from the reader test, not blanket rules.
4. **Identity bars per conversion** — dual proof (asl path == sigil path == current
   bytes) both shapes before each `.asm` retire; a determinism probe (double
   generate → identical bytes); the fresh-worktree bar from Q2 as the parcel's
   acceptance gate.
5. **The retirement set** — which generated `.asm` die HERE vs at Stage 2
   (`act_descriptor.asm` is a row-5 code-flip twin — does it ride here or wait?),
   with per-row kill-list updates same-commit.
6. **The flip interface** — what Stage 1/Stage 2 inherit: which files remain
   residual-AS after this parcel, and confirm `verify_emit_bin.py`'s retirement
   condition (design §1.5) — it retires only when the generated `.asm`/`.bin`
   twinning it checks goes single-sourced.
