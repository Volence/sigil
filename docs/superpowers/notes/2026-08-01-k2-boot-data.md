## §1 — The hole mechanism as-landed (the headline)

The conv-h2 STOP feared the $3FE hole needed a new `.emp` absolute-org / reserved-
hole surface OR a chainer inter-module-hole mechanism. **Neither was needed.** The
realization: the "$3FE hole" is not an empty gap — it is where the separately-chained
`z80_init` idle program physically LANDS. In the final ROM the boot region is
CONTIGUOUS: `[head 54B][z80 idle 38B][tail 14B]` (no-sound) or `[head 54B][blob][tail
14B]` (sound-on). The AS twin's `org $3FE` existed only because the idle was a
separate module the AS cursor had to *skip*; native placement packs the three sections
contiguously by declared order, so the idle occupies the gap naturally.

**As-landed:** `boot_data.emp` = TWO sections:
- `boot_head` — the 54-byte head (`BootData` movem preload + `BootData_VDPRegs` 24
  reg bytes + VRAM DMA-fill), then the resident driver blob (`data Z80_Sound_Start =
  if SOUND_DRIVER_ENABLED == 1 { ShapeBlob } else { Data.empty }`, `embed`) bracketed by
  `Z80_Sound_End`.
- `boot_tail` — `BootData_PostBlob` (PSG silence + post-DMA VDP commands, 14 B) +
  the `BootData_End` terminus label.

Placement (unchanged packer, `packed_true_bases` contiguity walk):
- **sound-off** (config_b, demo, demo_debug): `boot_head` @ BootData (frozen) ends at
  $3d8; `engine.z80_init`'s `Z80_IdleProgram` packs $3d8..$3fe; `boot_tail` packs at
  $3fe by contiguity. Map order `BootData < Z80_IdleProgram < BootData_PostBlob`.
- **sound-on** (s4, s4_debug, config_a): `z80_init` is absent from the registry; the
  blob rides `boot_head`; `boot_tail` abuts it.

**The one real requirement:** a `BootData_End` frozen boundary key in all 6 tables.
An `.emp` ROM section gets a cosmetic base 0 from `place_sections` (the chainer
recomputes), so a label-less tail would sort to the front — the AS residual got its
ordering from asl's baked lma for free; the `.emp` tail needs the frozen pin instead.
`BootData_End` (offset 14 = the tail's only frozen-keyed label) gives `boot_tail` its
provisional base (`table[BootData_End] − 14 = $3fe`). This is the SAME move z80_init's
own port made (Z80_IdleProgram / Z80_IdleProgram_End are already in the tables).

The K1 map's `[[hole]] after = "Z80_IdleProgram" at = 0x3FE filled_by =
"engine.z80_init"` row is now REAL: `validate_placement` checks the `after` label
resolves (K1), and the ordering + the `BootData_End` pin make the fill + resume
byte-exact (K2). A drift in either direction moves `boot_tail`'s base and fails the
whole-ROM anchor gate loud.

## §3 — The port map

| AS (`boot_data.asm`) | `.emp` (`boot_data.emp`) |
|---|---|
| `BootData:` movem head (3 w + 5 l) | `pub proc BootData` in `boot_head` (26 B) |
| `BootData_VDPRegs:` 24 dc.b + DMA fill | `pub proc BootData_VDPRegs` (28 B) |
| `ifdef SOUND` BINCLUDE blob / `else` `org $3FE` | `data Z80_Sound_Start = if SOUND { ShapeBlob } else { Data.empty }` (embed) + `data Z80_Sound_End` |
| PSG silence + post-DMA cmds | `pub proc BootData_PostBlob` in `boot_tail` (14 B) |
| `BootData_End:` | `pub data BootData_End = Data.empty` |
| `Z80_SOUND_SIZE = End − Start` | `pub equ Z80_SOUND_SIZE = extern("Z80_Sound_End") − extern("Z80_Sound_Start")` |
| `Z80_IDLE_SIZE = $3FE − $3D8` | `pub equ Z80_IDLE_SIZE = $3FE − $3D8` |
| `vdpComm`/`vdpReg`/`bytesToLcnt` macros | `use engine.vdp.vdp_comm` + local `vdp_reg`/`bytes_to_lcnt` comptime fns |
| the `if/fatal` assert wall | comptime evenness `ensure`s + frozen pins + whole-ROM anchor gate |

**Two `.emp` idioms found (worth noting):**
1. A comptime-fn CALL in an asm-proc `dc` operand parses as an addressing mode
   (`bytes_to_lcnt($10000)` → `[dc.operand]`). Fold to consts first, emit bare names.
2. `.emp` has no module-scope `if` around section/item declarations (`ast::Item` has
   no `If`), so a shape-varying section STRUCTURE is not expressible — hence the
   FIXED two-section layout (blob is a conditional `data` ITEM, not a conditional
   section). And `.len` off a conditional-const embed yields "unit"; the blob length
   comes from the AS-faithful link difference `Z80_Sound_End − Z80_Sound_Start`
   instead. A shape's blob is comptime-selected (`const ShapeBlob = if DEBUG {…}`)
   and referenced ONLY in the sound-on branch, so no-sound shapes never force the
   embed of a file their build never generates (consts are lazy).
