## 1. The confirmed architecture — extend the seam-2 whole-ROM template

The all-gates-ON native driver is the seam-2 whole-ROM gate
(`crates/sigil-cli/tests/seam2_sfx_rom.rs`, the exact template) with the code
gates added and every ported `.emp` placed:

1. `ensure_generated(aeon)` — emit ALL sound blobs first (seam1::emit_sound_blob +
   the six seam2:: emit_* fns, verbatim from `seam2_sfx_rom.rs:49-58`). The AS
   residual BINCLUDEs these — the sound stack is already native; the BINCLUDE is
   just how those native bytes enter the AS-assembled residual (design §1.4).
2. Assemble the AS residual with **all 53 `SIGIL_EMP_*` gates ON** + the sound
   gates (`SIGIL_EMP_DAC/MT/SFX`, NO `_BODY_STUB`) — new helper
   `assemble_native_all_gates_as_side(aeon, debug)`, structurally
   `assemble_seam2_sfx_rom_as_side` (`lib.rs:1307`) with the 53 defines appended.
3. For each registry entry (§3): lower the `.emp` with its shape defines, place its
   `<section>` at `pins::REGION.{plain,debug}_base` via a per-section map — the
   `placed_emp` pattern (`mixed_offcanonical_rom.rs:86-138`).
4. Concatenate AS-residual sections + all placed `.emp` sections → ONE
   `resolve_layout` + `link` + `emit_rom` → compare via
   `assert_rom_matches_convsym(rom, refrom, pins::ASSEMBLED_LEN, …)` against the
   live asl `s4.bin`/`s4.debug.bin` (asl is the live witness — Stage 1).

## 2. Why this is de-risked

- **Placement registry already exists as `pins.rs`** — every gated module has a
  `Region { plain_base, debug_base, plain_len, debug_len }` (1178 lines, generated
  by `repin`). LMA = `pins::REGION.{plain,debug}_base`. No per-shape address
  guessing.
- **Section names are self-declared** — every gated `.emp` opens
  `module <path> in <section>`, and `<section>` == the lowercase gate name (two
  spellings differ: `s4lz_decompress.emp in s4lz`, `zx0_decompress.emp in zx0`).
  `place_sections` (`sigil-frontend-emp/src/resolve/mod.rs:360`) maps section →
  map region.
- **Every piece is individually proven** — 39/53 gates have whole-ROM tranche
  gates in `mixed_dac_rom.rs`; all 53 have `*_port.rs` window oracles; the sound
  stack has the seam gates. S1.1 is the INTEGRATION (all at once), not new lowering.

### 3a. The three canonically-empty consumers
`game_debug`, `sound_debug`, `z80_init` emit ZERO bytes in every shipped shape
(`mixed_offcanonical_rom.rs:1-8`). In the CANONICAL native build (gates 1/2) they
contribute nothing — either skip placement or place with zero length. They are
NON-empty only in Config-A (game_debug/sound_debug) / Config-B (z80_init), which
gates 3/4 build with the extra defines (§5, mixed_offcanonical_rom CONFIG_A/B).

## 4. Why a partial driver can't be a partial checkpoint

The 53 modules are mutually symbol-dependent (cross-seam `jsr`/`abs.w`/imm32 to
each other's `pub proc`s + shared RAM labels). Place only some and the link fails
on the unplaced ones' unresolved symbols — so there is no meaningful "half" link.
Checkpoint-1's question ("which of the 14 first-time placements fought") is only
answerable once ALL 53 are in one link. Hence the full registry must land before
the first honest run. This is the reason for the single-pass build, not scope creep.

## 5. Known per-module subtleties to handle in the build (the likely fights)

- **The emp debug flag name.** The `.emp` modules read a define for debug-shape
  bodies. Confirm it is `DEBUG` (as `mixed_offcanonical_rom.rs` GAME_DEBUG_EMP_DEFS
  uses `("DEBUG",1)`, NOT `__DEBUG__`). Pass it only in the debug shape, only to
  the shape-conditional modules.
- **The 14 first-time real-image placements** (BG BG_ANIM CAMERA CORE DPLC
  ENTITY_WINDOW LOAD_OBJECT OBJDEFS PARALLAX PLANE_BUFFER SECTION SPRITES
  TILE_CACHE VECTORS) have NEVER been placed in the real image — expect the fights
  here (cross-seam symbol resolution, section-size vs pins length, VECTORS at org 0
  overlapping the reset section). Report each per checkpoint 1.
- **OBJDEFS section** — `data/objdefs/test_objects.emp` has no `module … in`;
  resolve its placement section before wiring.
- **TEST_OBJECTS = one gate, two modules** (test_solid.emp + test_particle.emp).
- **Helper modules** — `sound_debug` needs `z80_bus.emp` concatenated (the
  `extra_modules` param of `placed_emp`, `mixed_offcanonical_rom.rs:106-113`).
- **Sound BINCLUDE paths** must exist — `ensure_generated` writes them to
  `engine/sound/generated/` (gitignored); run it every build.
