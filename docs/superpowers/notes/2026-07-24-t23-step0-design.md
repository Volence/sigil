  (Sonic4-shape org addresses; the gate define must never be set for other

- **convsym constraint (measured, load-bearing):** build.sh appends the
  convsym symbol table to the ROM (`-a`), so ANY new label/equ changes ROM
  bytes. The split renames nothing and adds nothing; the assert wall uses
  ONLY existing symbols and `if/fatal` (emits nothing). Byte-neutrality is
  therefore exact — proven by dual rebuild before commit.

### The boot_data.asm assert wall (finalized list — step-0 deliverable)

The `(a5)+` cursor protocol in boot.emp is guarded AS-side (both assemblers
run the .asm universe). Four asserts, all over existing symbols:

1. `(BootData_VDPRegs-BootData) <> 3*2+5*4` → fatal — the movem-preload
   head (3 `dc.w` + 5 `dc.l`) must match the code's
   `movem.w (a5)+, d5-d7` / `movem.l (a5)+, a0-a4` widths/order.
2. Blob-start offset: `(Z80_Sound_Start-BootData) <> 54` (sound arm) /
   `(Z80_IdleProgram-BootData) <> 54` (idle arm) → fatal — 26 (head) + 24
   (VDP reg bytes, the `moveq #23` loop) + 4 (fill command) consumed before
   `.load_z80` starts.
3. Post-blob evenness: `Z80_SOUND_SIZE & 1` / `Z80_IDLE_SIZE & 1` → fatal —
   the `align 2` after the blob must emit NOTHING, or the cursor (which
   advances exactly SIZE bytes) drifts off the PSG bytes.
4. Total-layout lock: `(BootData_End-BootData) <> 54+<SIZE>+4+10` → fatal —
   blob + PSG(4) + restore-word(2) + two post-DMA longs(8), no hidden pad.

## Single-proc shape

Warm_Boot/Cold_Boot have ZERO external refs (verified: only vectors.asm
references EntryPoint) → ONE `pub proc EntryPoint` with local labels
(`.warm_boot`/`.wait_dma`/`.cold_boot`/`.no_tmss`/…). The proc-level
`.wait_z80` (boot.asm:64) coexists with the stop_z80 template's hygienic
`.wait_z80` mint (per-site hygiene — verified class, z80_bus doc).
Contract: `pub proc EntryPoint () clobbers(d0-d7/a0-a6)` — boot never
returns (`bra.w GameLoop` tail), the honest ⊤ bound (game_loop precedent).

Faithful-port C-material (no cleverness — carry comments present-tense):
- d0 = 0 invariant from boot.asm:54 (btst d0 = bit 0; movea.l d0 = zero).
- The wrapping RAM-clear (`movea.l d0, a6`; `move.l d0, -(a6)` predecrements
  $00000000 → $FFFFFFFC, 64KB top-down) + regs-from-cleared-RAM zeroing
  (`movem.l (RAM_Start).w, d0-a6`).
- DMA-fill parallelism window (fill trigger :55 → wait :101): nothing
  between touches the VDP data port (C3 input).
- Interrupt bring-up ordering (:184-200): HBlank slot rte-patched BEFORE
  unmask; VInt shadow+hardware BEFORE `enableInts` (comment block carried).
- YM2612 delay `moveq #25` dbf ≈ 264 cyc ≥ 192 (C1); keyoff channels
  $04-$06 subq-inside-dbf (C2).
- `align 2` at boot.asm:98 (mid-code, emits nothing — code is even):
  step-3 adjudication, twin-lockstep whatever the call.
